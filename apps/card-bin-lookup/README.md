## 🌟 核心升级与特性

### 1. 现代化 Light 视觉色调 (Clean Light Fintech Theme)
- 采用 Apple / Stripe 风格的优雅白银清爽质感，浅灰底色搭配弥散光感阴影；
- 保留 3D 拟真信用卡的金属高光与各卡组织品牌（Visa/万事达/运通/银联）流光渐变材质，在浅色桌面上质感尤为出众。

### 2. 前端访问授权防护锁 (Access Password Gate)
- 初次访问弹出现代化毛玻璃授权卡片，拦截非授权访客与爬虫；
- 授权成功后自动记忆在 `localStorage` 中，后续无需重复输入；
- 顶部导航栏提供 `🔒 已授权 (点击锁定)` 快捷按钮，支持一键登出与锁定；
- 服务端核心 API (`/api/lookup` 与 `/api/batch`) 均经过后端密码强校验，即使绕过前端直接调用 API 也必须携带 `X-Access-Password`。

### 3. 严格单 IP 限流（1次/60秒）(Strict Rate Limiting)
- 单个 IP 地址在 60 秒内仅允许发起 1 次查询，彻底杜绝高频并发消耗 Neutrino API 免费额度；
- 前端按钮在每次发起查询后自动进入 60 秒平滑倒计时（`频率冷却中 (59s)...`），并在超出频率时友好返回精确剩余秒数。

### 4. 10 位子卡段精准穿透与免费额度持久缓存
- 兼容 6 位传统 BIN、8 位新标准 BIN 及 9~10 位现代虚拟卡/车队卡扩展子卡段；
- 首次查询的卡 BIN 写入本地 SQLite 数据库，相同卡号再次查询 **0 毫秒响应，消耗 0 外部 API 额度**。
